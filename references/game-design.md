# 搞笑小遊戲設計公式

## 一頁企劃（動手前先寫這個）
```
核心動作：一句話（例：移動屁股對準馬桶、按住出力）
操作：    滑鼠/拖曳 = 位置或方向；按住 = 力道；（手機另給大按鈕＋陀螺儀選配）
成功條件：命中率 ≥ 60% / 投進 3 球
難度旋鈕：量、速度、晃動、目標大小、目標移動、提示有無
突發事件：3~5 種，第 2 關開始一關多一種
結算：    分數 + 等級 + 好笑稱號
全破台詞：一句可以截圖分享的話（例：「我很會大便！！讚」）
```

## 難度曲線：用「表格」管理
所有關卡參數集中在 `LEVELS` 陣列，一關一列，逐步加：
| 旋鈕 | 第 1 關 | 最後一關 | 說明 |
|---|---|---|---|
| 量／次數 | 少 | 2 倍以上 | 玩得久＝出錯機會多 |
| 速度 | ×1 | ×1.8 | 下落／力道條擺動速度 |
| 晃動 | 0 | 大 | 輸入加上 sin 雜訊，讓瞄準不穩 |
| 目標 | 大、靜止 | 小、會動、會歪 | 同一個模型換 scale/rotation 就是新關卡 |
| 提示 | 有落點／拋物線 | 無 | 第 3 關起拿掉 |
第 1 關要能在 3~4 秒內上手、幾乎必過。

## 好笑的來源
1. **反差**：很嚴肅地做很蠢的事（例：電子配樂越來越緊張，但你只是在上廁所）。
2. **社死**：被看到、被抓到（推門、老闆巡視）。
3. **荒謬的打擾**：蛇從馬桶出來、吉娃娃衝進來問「主人你好了嗎」、阿飄借衛生紙。
4. **失敗也有獎**：失敗結算給好笑的稱號（「越擦越髒的藝術家」「最後用襪子擦的人」）。
5. **可愛化**：敏感的東西換成可愛代替物（屁股 → 桃子 🍑）。

## 突發事件設計模板
每個事件都要有：**預告（聲音＋字）→ 玩家可以做的反應（按鈕／連按／停手）→ 成功與失敗兩種結果**。
| 事件 | 預告 | 玩家反應 | 失敗懲罰 |
|---|---|---|---|
| 有人推門 | 敲門聲＋「有人嗎？」 | 連按「頂住門」 | 扣忍耐值＋畫面閃白 |
| 停電 | 燈閃幾下 | 只能靠手電筒照到的範圍瞄準 | （本身就是難度） |
| 阿飄借衛生紙 | 陰森低語 | 借／不借（兩難） | 借＝後面少一張紙；不借＝被嚇 |
| 馬桶蛇 | 「蛇！」＋倒數 | 倒數內完成或砸中牠 | 被咬、扣血 |
| 吉娃娃 | 「主人你好了嗎」＋狂吠 | 連按「坐下」 | 晃動變大 |
| 電風扇（範例） | 「誰開電風扇」 | 修正瞄準 | （風力本身） |
| 老闆巡視（範例） | 畫面變暗＋耳語 | 那幾秒不要動作 | 沒收一次機會 |
事件觸發點用「進度」決定（剩餘量 ≤ x%），不要用固定秒數，玩家快慢都會遇到。

## 小遊戲接小遊戲
主玩法結束後接一段 10 秒的小遊戲（例：擦屁股），用 2D canvas 疊在畫面上做就好：
- 一個清楚的量表（乾淨度）、一個風險量表（太用力會破）、一個資源（衛生紙張數）
- 評分 S~D＋稱號，跟主玩法分數一起結算

## 角色與版權
不要畫有版權的角色：貞子、Sonic、寶可夢、迪士尼角色等等。使用者要求時，說明原因並提出一個原創替代：保留「功能」（嚇人、搗亂），換掉外觀（例：貞子 → 全身纏衛生紙的阿飄）。
